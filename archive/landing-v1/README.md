# Landing NEXO — versão anterior

Snapshot da landing que ocupava `/landing` antes da publicação da v2 em
24/08/2026.

O código original foi preservado em `src/app/landing/`, mantendo a mesma
estrutura relativa que tinha no projeto. Para restaurar, substitua a pasta
`src/app/landing/` do projeto por esta cópia.

A versão também usa as classes globais `.lp-*` que permanecem em
`src/app/globals.css` no commit de arquivamento.
