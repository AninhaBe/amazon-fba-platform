# Ícones de marketplaces

Os arquivos desta pasta são usados apenas para identificar integrações dentro do SellerCore. As marcas pertencem aos respectivos titulares.

- `amazon.svg`: Amazon “A” icon, Wikimedia Commons, marca registrada e imagem simples indicada como domínio público.
- `mercado-livre.svg`: glifo Mercado Libre, SVG Repo, CC0.
- `shopee.svg`: glifo Shopee distribuído pelo projeto Simple Icons, CC0.
- `tiktok-shop.svg`: glifo TikTok derivado do Ionicons, Wikimedia Commons, CC0. Seu uso no produto identifica tecnicamente o conector; materiais promocionais devem seguir separadamente as regras de marca do TikTok Shop.
